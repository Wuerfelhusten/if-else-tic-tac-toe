# If/Else Tic-Tac-Toe

If/Else Tic-Tac-Toe is a polished, modern desktop interpretation of the classic two-player game. It pairs an intentionally absurd generated engine with a restrained dark Qt interface that feels crisp, focused, and complete.

## The Experience

The interface is designed around the board instead of surrounding it with unnecessary decoration. A near-black canvas, precise spacing, and a compact status banner keep every move easy to read. X uses a vivid teal, O uses a warm coral, and the winning line changes to gold at the end of a round. Subtle hover states make empty cells feel responsive, while the full-width New Game button provides an immediate and predictable way to begin again.

The result is a clean modern game window with:

- a balanced, high-contrast dark theme;
- a stable 3-by-3 board with generous click targets;
- clear turn, win, and draw messaging;
- distinct colors for X, O, and the winning line;
- responsive hover and pressed states; and
- instant round resets without restarting the application.

## The Twist

The runtime game logic uses only explicit `if`, `elif`, and `else` branches. The generator writes the complete game tree chronologically, from every possible opening move through every legal win or draw. Equivalent board states are deliberately repeated when different move histories lead to them.

Every generated condition has an English comment and a blank line after its block header. The output follows PEP 8, including the 79-character line limit. To keep indentation within that limit, the tree is divided into explicitly named subtree functions after every three moves. Nothing is deduplicated.

## Generate and Run

The project uses `uv` exclusively. No separately managed system Python or manual virtual environment is required.

```powershell
uv sync
uv run generator.py
uv run main.py
```

The generated `main.py` contains the complete engine, Qt interface, dark theme, and application entry point. Its size exceeds GitHub's regular file limit, so the repository stores it through Git LFS.

## Test

```powershell
uv run python -m unittest discover -s tests
```

The tests validate representative wins, draws, invalid moves, generated syntax, English condition comments, deliberate blank lines, the absence of runtime loops, and the PEP 8 line-length limit.

## Runtime Logs

The generator logs how many seconds it needed to build and write the complete `main.py`. The generated application logs its total runtime in seconds after the Qt window closes. Both messages use Python's standard logging module and appear in the console.

## Deliberate Scale

The fully expanded chronological game tree currently produces approximately 11.7 million lines and 506 MB of Python source. Its first launch needs about a minute to compile the generated bytecode. Later launches use Python's cache and start considerably faster.
